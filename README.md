# iPad Air 中文吐槽站

一个借鉴 Apple 官网视觉风格的中文单页网站，用产品展示动画和反讽文案，聊聊 iPad Air 的 60Hz 屏幕、性能与配件价格。

**超拉胯，垃圾体验来自 60Hz。**

## 网站特色

- **蓝色动态首页**：产品出场动画，搭配从小球展开的“先看槽点”胶囊与同色蓝色重播球；重播按钮只显示回转图标。
- **先刷重点**：四张卡片自动轮播，M4 影片从游戏画面过渡到芯片，支持暂停、翻页和触控滑动。
- **定睛细看**：“所有颜色”加蓝色、紫色、星光色、深空灰色，共五个选项；通过“看看iPad、看看细节、看看边框、看看全景”切换四个角度，使用 20 张官方图片。所有颜色，只有四个。
- **颜色灵动岛**：颜色面板从小球展开，选项依次浮现，选中底色和细环平滑跟随。
- **产品场景动画**：Apple 智能隐私锁、妙控键盘与 Apple Pencil 磁吸展示，以及 Pencil 电量弹窗；提前预热附近影片，减少进入场景时的等待。
- **两种身量**：11 英寸与 13 英寸按钮可交互切换，调用官网正向、反向旋转影片，转到对应尺寸的官方终帧；播放受限时显示相应静态图。
- **一笔开山水，一笔空钱包**：中国风山水画面，搭配轻微的滚动缩放，标题可直接修改。
- **手机与电脑适配**：响应式布局、手机导航逐项浮现，并支持系统“减少动态效果”设置。
- **请我喝杯咖啡**：末页紫色胶囊打开作者提供的微信收款码图片，支持关闭按钮、点击遮罩与 Esc 关闭。

## 技术与文件

使用原生 **HTML、CSS 和 JavaScript**，无需安装依赖或编译。图片和视频随项目保存在本地。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、中文文案和素材引用 |
| `style.css` | 页面样式、响应式布局和 CSS 动画 |
| `hero-controls.css`、`color-island.css`、`support.css` | 首页灵动岛、颜色面板和图片弹窗样式 |
| `script.js` | 首页动画、导航及滚动交互 |
| `highlights.js` | 重点卡片轮播和 M4 视频播放 |
| `media.js` | 隐私锁、磁吸动画及播放恢复逻辑 |
| `gallery.js` | 多角度展示、颜色面板进场与选中高亮 |
| `support.js` | 图片弹窗、关闭交互及焦点管理 |
| `sizes.js`、`sizes.css` | 11/13 英寸尺寸切换、旋转影片及响应式样式 |
| `effects.js`、`scenes.js` | 图片入场和滚动场景效果 |
| `assets/` | 图片、视频和图标 |

## 本地预览与修改

1. 下载或解压项目，用 VS Code 打开包含 `index.html` 的文件夹。
2. 通过本地静态服务器或编辑器的本地预览扩展打开网页。
3. 修改 `index.html` 中的文案，或调整 `style.css` 中的样式，刷新即可查看。

部署时完整上传项目文件及 `assets/` 目录，保留相对路径。文件夹与压缩包名称仍为 **ipad-air-roast-XR**，本轮缓存标记为 **XR-4**；媒体兼容处理与检查范围见 [检查记录](VERIFICATION.md)。自动播放效果受浏览器与系统设置影响，受限时保留静态画面。
